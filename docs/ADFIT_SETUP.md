# 수소한눈 카카오 AdFit 운영

수소한눈 전용 Web 매체 `수소한눈`에서 발급한 320×100 광고 단위 세 개를 사용한다. 다른 서비스에서 이 ID를 재사용하지 않는다.

| 지면 | 광고 단위 | 노출 조건 |
|---|---|---|
| 목록 인피드 | `DAN-br2FK1ogdWkvz5PH` | 검색 결과가 7개 이상일 때 6번째, 13개 이상일 때 12번째 카드 뒤에서 실제 화면에 가까워졌을 때 요청 |
| 충전소 상세 하단 | `DAN-wBqWgG5o345q4Zn9` | 사용자가 충전소 상세를 실제로 연 뒤, 하단 지면이 화면에 가까워졌을 때 한 번 요청 |
| 하단 접이식 | `DAN-YJZxeizun0GjEKVU` | 기본 열림. 사용자가 접거나 다시 펼친 상태를 같은 세션에서 유지하고 광고는 한 번만 요청 |

배포 빌드는 GitHub Actions Variables `PUBLIC_ADFIT_LIST_UNIT`, `PUBLIC_ADFIT_DETAIL_UNIT`, `PUBLIC_ADFIT_BOTTOM_UNIT`으로 같은 값을 주입할 수 있다. 저장소의 `public/ad-config.js`는 로컬·비상 빌드에서도 지면 구성이 유지되도록 전용 공개 ID를 기록한다.

## 공통 동작

- 광고는 각 지면에서 한 번만 요청하며 검색·정렬·지도 이동·상세 전환으로 자체 새로고침하지 않는다.
- 목록은 6건 간격으로 배치하되 상세·하단을 포함한 페이지당 최대 4개 제한 때문에 6·12번째 두 곳까지만 사용한다.
- 하단 접이식 손잡이는 광고 영역 밖에 두고, 펼친 높이만큼 지도·상세 공간을 확보하며 접으면 광고 공간을 반환한다.
- 컨테이너 폭이 320px보다 좁거나 광고 ID·규격이 잘못된 경우 요청하지 않고 지면을 숨긴다.
- SDK 오류, NOAD 콜백, 30초 안에 광고 프레임이 생성되지 않는 경우 광고 DOM과 빈 공간을 제거한다.
- `AdMobNative/1` User-Agent를 사용하는 Android WebView에서는 웹 AdFit 요청과 광고 컨테이너를 모두 차단한다.
- 광고 차단·오프라인·미승인·심사 중 상태가 검색, 지도, 상세정보 이용을 방해하지 않는다.
- 광고 클릭을 유도하는 문구, 자체 새로고침, 콘텐츠를 가리는 고정 광고는 사용하지 않는다.

## 출시 확인

1. `npm run check`, `npm test`, `npm run build`를 통과한다.
2. 일반 브라우저 운영 URL에서 목록·상세 광고가 각각 한 번만 요청되는지 확인한다.
3. 319px 이하, 광고 차단, 느린 네트워크, NOAD에서 빈 공간이 사라지는지 확인한다.
4. `AdMobNative/1` User-Agent에서 AdFit 스크립트가 전혀 생성되지 않는지 확인한다.
5. AdFit 매체 심사 상태와 광고 단위 상태를 확인한다. 스크립트 설치 후 실제 호출까지 최대 30분이 걸릴 수 있다.
6. Android Play Console의 `광고 포함` 선언을 `예`로 맞춘다. 네이티브 광고 SDK와 `AD_ID` 권한이 없다면 광고 ID 사용 여부는 실제 구현에 맞게 별도 답변한다.
