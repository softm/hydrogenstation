# 수소한눈 데이터 수집·검증·배포 계약

## 흐름

한국석유관리원 공개 지도 조회 → 명시 필드 정규화 → ID/좌표/급감 검증 → immutable JSON·gzip → manifest 마지막 교체 → 빌드에서 gzip·SHA·집계 검증 → GitHub Pages → 브라우저에서 재검증 → 지도·목록·수집현황.

## 제공처

| 출처 | 실제 확인 경로 | 사용 필드·범위 |
|---|---|---|
| [하잉 충전소 검색](https://www.h2nbiz.or.kr/rt/sch/rtSearch.do?tabNo=1) | 해당 페이지가 사용하는 `POST /rt/sts/inf/getAjaxChrstnList.do`, body `{}` | 충전소 관리번호·시설명·주소·좌표·가격·대표번호·차종·설비 표기 압력·시간표·운영·대기. 한 번의 응답을 전체 처리하되 전국 전체 시설과 동일시하지 않음 |
| [공공 운영정보](https://www.data.go.kr/data/15133332/openapi.do) | `GET https://apis.data.go.kr/B552532/h2nbiz_2/operationInfo?serviceKey=…` | 공식 Swagger 2026-10-21 확인: 관리번호, 도로명주소, `lon`, `let`, 원/kg `ntsl_pc`, 차종, 운영표, 설비, 삭제여부 |
| [공공 실시간정보](https://www.data.go.kr/data/15133338/openapi.do) | `GET https://apis.data.go.kr/B552532/h2nbiz_3/currentInfo?serviceKey=…` | 관리번호로 결합, 상태·대기차수·혼잡. 문서상 미사용인 완충가능대수는 표시하지 않음 |

공공 API는 `header.resultCode`, `body.totalCount`, `body.items.item`을 검증한다. 확인된 문서에서 페이지 파라미터가 제공되지 않아 임의 파라미터를 만들지 않는다. `totalCount`와 실제 행수가 다르면 배포 데이터 교체를 중단한다. 원본을 검색·스크래핑해서 얻은 내부 웹 경로는 공공 API의 장기 안정성 계약을 대신하지 않는다.

## 시각과 상태

| 필드 | 의미·용도 |
|---|---|
| `observedAt` | 우리 수집기가 해당 응답을 성공적으로 확보한 시각. 갱신 실패 시 변경하지 않음 |
| `upstreamCheckedAt` | 공개 조회의 `eqpLastMdfcnDt`: 설비 원천 갱신 시각. 상태와 함께 15분 이내인지 확인 |
| `operationChangedAt` | `operLastMdfcnDt`: 운영상태 변경 시각. 오래됐다고 고장으로 판단하거나 heartbeat로 사용하지 않음 |
| 공개 응답의 `lastMdfcnDt` | `12분전` 같은 상대 문자열이므로 신선도 판정에 사용하지 않음 |
| 공공 실시간 API `last_mdfcn_dt` | 문서상 운영상태갱신일자. heartbeat 여부를 검증하지 않았으므로 `operationChangedAt`에만 기록 |

- 원천·수집이 모두 15분 이내이고, 점검·고장·마감·휴무·T/T교체가 아닌 명시 상태만 영업 확인 필터에 포함.
- 0대는 알려진 0이며 빈 값은 미제공. 최신성이 불명확하면 대기 적은순 정렬의 맨 뒤에 둔다.
- 설비 표기 800 bar를 700 bar 승용 지원으로 바꾸지 않는다. 차종은 별도 명시 값으로 판단한다.
- 오늘 시간표는 KST 요일 기준. 공휴일·임시 휴무는 정기표로 추정하지 않고 공식 확인을 안내한다.

## 실패·품질 보존

- ID 누락·중복, 빈 응답, 좌표 보유 80% 미만, 동일 출처의 시설 수 25% 이상 급감은 교체 중단.
- 임시 파일 후 manifest 교체. 데이터 파일은 내용 SHA 기반 이름을 사용하므로 CDN에서 서로 다른 버전이 섞여도 조용히 통과하지 않는다.
- 수집 실패 시 기존 manifest·파일·확인 시각 유지. 별도 `collection-status.json`만 안전한 오류코드와 시도 시각으로 갱신.
- 오류 URL·응답 본문은 기록하지 않는다. 서비스 키와 원본 담당자 정보가 로그/배포 데이터에 포함되지 않도록 허용 필드만 직렬화.
- 매번 캐시를 복구해 예약 실행 사이의 마지막 정상본 보존. 캐시가 만료되면 저장소 최초 정상본을 사용하며 오래된 시각을 숨기지 않는다.
- `data-status.html`에서 실제 gzip 압축해제, SHA, 전체·지역·좌표 집계를 검사한다. 브라우저가 gzip 스트림을 지원하지 않으면 JSON 대체본을 동일 SHA로 검증한다.

## 운영

| 작업 | 방식 |
|---|---|
| 평상시 수집 | 매시 7·22·37·52분 Actions. 공개 경로 기준 1일 96요청. 예약은 best effort |
| 공공 API 설정 후 | 2요청/실행, 기본 1일 192요청. 승인된 계정의 실제 할당량 확인 필요 |
| 키 미설정 | 기본 공개 지도 경로 사용. API 인증 성공이라고 보고하지 않음 |
| 수동 복구 | Actions Run workflow. 사용자 정기 수동 작업 불필요 |
| 긴급 중지 | `PAUSE_H2_COLLECTION=true` |
| 빌드·배포 | 한 workflow만 `dist/`를 Pages 루트로 배포. 확인 단계가 실제 배포 revision·gzip 파일·수집현황 페이지 대조 |

현재 한계: 전국 시설 전체와의 별도 대조, 공공 API 인증 및 실서비스 응답 검증, 공휴일/일자별 운영변경 상세, 사이트 전용 광고단위·광고 승인, 대기 알림·계정 동기화는 확인 또는 추가 연결이 필요하다. 구현·배포 완료와 이 조건들을 혼동하지 않는다.
